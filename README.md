# 우리 반 캐릭터 진도 위젯

Windows 바탕 화면 아래쪽, 작업표시줄 바로 위에 반별 캐릭터가 표시되는 진도 위젯입니다. 캐릭터는 해당 반의 전체 활동 완료율에 맞춰 트랙을 이동합니다.

## 주요 기능

- 캐릭터를 클릭하면 해당 반의 진도창이 열립니다.
- 차시와 활동은 모든 반이 함께 사용하는 공통 수업 계획이며, 완료 체크와 메모는 반마다 따로 저장됩니다.
- 캐릭터 우클릭 메뉴의 `수업 계획 설정`에서 차시·활동을 추가하거나 수정·삭제하고 `↑`·`↓`로 순서를 바꿀 수 있습니다.
- 진도창에서도 활동과 차시를 빠르게 추가하고 `⋯` 메뉴에서 수정·순서 변경·삭제할 수 있습니다.
- 진도창의 `↶` 버튼 또는 Ctrl+Z로 최근 계획 변경을 한 번 되돌릴 수 있습니다.
- `반·캐릭터 설정`에서 반 수, 반 이름, 캐릭터 이미지, 크기, 대기 동작과 진도율 표시 여부를 설정합니다.
- 캐릭터 이미지는 `이미지 선택` 버튼으로 PNG, JPG, WEBP, BMP, GIF 파일을 지정합니다. 이미지 드래그앤드롭은 지원하지 않습니다.
- 체크 상태, 수업 계획과 반별 메모는 `%APPDATA%\UsagiJindo`에 저장되어 프로그램을 다시 설치해도 유지됩니다.

## 업데이트 기능

배포된 앱은 시작할 때 공개 GitHub Release의 최신 버전을 확인합니다. 새 버전이 있으면 변경 내용과 버전을 안내하고, 사용자가 동의한 경우에만 `진도 위젯-v버전.exe` 설치 파일을 직접 내려받습니다.

GitHub 저장소 페이지는 열리지 않습니다. 저장 창의 기본 위치는 사용자의 `다운로드` 폴더이며, 다운로드가 끝나면 설치 파일이 저장된 폴더만 열립니다. 업데이트는 자동 설치하지 않습니다. 현재 진도 위젯을 종료한 뒤 내려받은 설치 EXE를 실행하면 됩니다.

다운로드한 파일은 GitHub Release가 제공하는 SHA-256 값으로 검증합니다. 자동 업데이트 ZIP, 앱 폴더 교체, 별도 업데이트 도우미와 바탕 화면의 업데이트 임시 폴더는 사용하지 않습니다.

`0.2.1` 설치본은 이전 ZIP 업데이트 방식을 사용하므로 `0.2.2` 설치 EXE를 한 번 직접 실행해야 합니다. `0.2.2`부터는 설치 EXE 직접 다운로드 방식이 적용됩니다.

## 설치와 배포

사용자에게 전달하는 배포 파일은 `진도 위젯-v버전.exe` 하나입니다. 설치 위치는 `%LOCALAPPDATA%\Programs\JindoWidget`으로 고정되며 설치 위치 선택 화면은 표시하지 않습니다. 바탕 화면에는 사용자가 선택한 경우 바로가기만 생성됩니다. 앱 실행에 필요한 내부 파일은 사용자에게 보이지 않는 설치 폴더 안에 저장됩니다.

새 버전을 배포할 때 `update_config.py`의 `APP_VERSION`을 사용하지 않은 새 번호로 올리고 main 브랜치에 커밋합니다. GitHub Actions는 설치 EXE 하나만 빌드하여 Artifact와 GitHub Release에 첨부합니다. 이미 같은 버전의 Release가 있으면 중복 게시하지 않으므로 매 배포마다 버전을 올려야 합니다.

직접 빌드하려면 Tcl/Tk가 포함된 Python 3와 Inno Setup 6 이상이 설치된 Windows에서 다음 명령을 실행합니다.

```powershell
python -m pip install -r requirements-build.txt
.\build_release.ps1
```

빌드가 성공하면 `release` 폴더에 `진도 위젯-v버전.exe` 하나가 만들어집니다. 이미지 드래그 기능을 사용하지 않으므로 `tkinterdnd2`는 필요하지 않습니다.

## 개발 실행

Python 3와 Tcl/Tk가 필요합니다. `시작하기.bat`을 더블클릭하면 처음 한 번 `%LOCALAPPDATA%` 아래에 별도 실행 환경을 만들고 Pillow를 설치합니다. 이후에는 준비된 환경을 사용합니다.

실행 중 모든 캐릭터를 종료하려면 캐릭터를 오른쪽 클릭하고 `전체 종료`를 선택합니다. `Ctrl+Shift+Q`도 종료 단축키입니다.

위젯은 프로그램에 캐릭터 원본 그림을 포함하지 않습니다. 각 사용자가 이용 권리를 가진 이미지를 `반·캐릭터 설정`에서 선택해야 합니다. 선택한 이미지는 `%APPDATA%\UsagiJindo\characters`에 복사되며 외부로 전송되지 않습니다.
